# Doodle Math Lab

Небольшая, расширяемая стартовая точка для личного **математического блокнота**. Здесь нет Lean, mathlib, KaTeX и внешних математических библиотек: это основа для вашей собственной системы и собственного проверщика доказательств.

## Запуск

Это статический проект — достаточно открыть `index.html` в браузере. Для корректной работы ES-модулей удобнее поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Устройство

```
index.html             # только разметка и подключение приложения
styles/main.css        # интерфейс, темы и адаптивность
src/main.js            # связывает UI и модули
src/core/evaluator.js  # безопасный мини-парсер выражений
src/modules/zero_natural.js       # модуль 0: натуральные числа
src/modules/one_add_subtract.js   # модуль 1: сложение и вычитание
src/modules/two_checker.js        # модуль 2: заготовка проверщика равенств
src/ui/notebook.js     # ячейки, история, сообщения об ошибках
tests/evaluator.test.mjs
```

## Как расширять

1. Добавьте следующий модуль как отдельный файл в `src/modules/`.
2. В `src/core/evaluator.js` добавляйте синтаксис только при необходимости и не используйте `eval`.
3. Замените содержимое `src/modules/two_checker.js` собственным проверщиком: UI уже передаёт ему строку с равенством.

### Синтаксис первого ядра

Поддерживаются натуральные числа (включая `0`), `+`, `-`, скобки и равенство `=` для проверки. Вычитание, которое потребовало бы отрицательного числа, намеренно является ошибкой.

```text
12 + 7
(12 + 7) - 4 = 15
```

Модуль 2 сейчас выполняет лишь вычислительную проверку равенства. Это не доказательство в строгом смысле — он оставлен маленькой и ясной точкой замены для вашего будущего ядра доказательств.
