# Doodle Math Lab

Небольшая, расширяемая стартовая точка для личного **HTML-проекта в духе Mathematica + Lean 4**. Это не заменяет ни Mathematica, ни Lean: браузерное ядро вычисляет простые выражения быстро и прозрачно, а отдельная панель хранит Lean-код для дальнейшей проверки в настоящем Lean 4 + mathlib окружении.

## Запуск

Это статический проект — достаточно открыть `index.html` в браузере. Для корректной работы ES-модулей удобнее поднять локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Устройство

```
index.html             # только разметка и подключение приложения
styles/main.css        # интерфейс, темы и адаптивность
src/main.js            # связывает UI и модули
src/core/evaluator.js  # безопасный мини-парсер и вычислитель
src/core/registry.js   # расширяемый реестр функций
src/ui/notebook.js     # ячейки, история, сообщения об ошибках
src/ui/latex.js        # предпросмотр LaTeX через KaTeX
src/ui/lean.js         # черновик Lean и экспорт файла
tests/evaluator.test.mjs
```

## Как расширять

1. Добавьте функцию в `src/core/registry.js` через `registry.define(...)`.
2. В `src/core/evaluator.js` при необходимости добавьте новый синтаксис, не используя `eval`.
3. Добавьте отдельный UI-модуль в `src/ui/` и подключите его из `src/main.js`.

### Синтаксис первого ядра

Поддерживаются числа, `+`, `-`, `*`, `/`, `^`, скобки, константы `pi`, `e`, а также `sin`, `cos`, `sqrt`, `abs`, `min`, `max`, `sum` и `mean`.

```text
sum(1, 2, 3) + sqrt(16)
sin(pi / 2)^2 + cos(pi / 2)^2
```

LaTeX-поле — это пока именно рендеринг формулы, а не преобразование LaTeX в выражение. Эта граница намеренная: парсер остаётся маленьким, понятным и безопасным.
