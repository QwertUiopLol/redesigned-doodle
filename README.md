# axiom

Небольшая браузерная основа для математической тетради и будущего проверщика доказательств. Проект намеренно не использует сборщик, фреймворк или сервер: откройте `index.html` в современном браузере либо запустите любой статический сервер.

## Что уже есть

- строки с выражениями, определениями `let` и утверждениями `theorem`;
- маленький рекурсивный парсер арифметики и сравнений;
- изолированные математические библиотеки в `js/libraries/`;
- исполняемая Peano-модель натуральных чисел: собственные `add`, `sub` и `mul`;
- отдельный исходный файл теории `theories/natural-semiring.ax`, содержащий
  индуктивный тип, определения операций и будущие цели доказательств;
- понятная точка для развития: расширяйте грамматику в `js/core/parser.js`, семантику в `js/core/engine.js`, а предметные знания — отдельными модулями.

## Быстрый старт

```bash
python3 -m http.server 8080
```

После этого откройте <http://localhost:8080>. Для прототипа полукольца введите
`:load natural-semiring`, затем используйте выражения наподобие
`nat.mul(nat.add(nat.two, nat.three), nat.two)`. В отличие от прежнего
арифметического примера, это вычисляет рекурсивные Peano-термы.

Чтобы добавить библиотеку, экспортируйте объект `{ id, label, install(engine) }`
и добавьте его в массив `libraries` в `js/app.js`. Рядом с исполняемым модулем
держите `.ax`-файл с читаемым формальным описанием теории.
